
# 🌐 My EC2 Website

This project is configured with a custom domain and secured using SSL certificates.
A custom domain was purchased and mapped to the EC2 public IP.<br>
DNS records (A record) were configured to point the domain to the EC2 instance.
SSL certificates were installed to enable HTTPS, ensuring secure communication between users and the server.
Nginx was used as a reverse proxy to handle domain routing and HTTPS configuration.



**🚀 Access the Website**<br>
👉 https://subodhmhaske.space<br>
Note: If EC2 is stopped by the admin the website may not work<br>

## 📌 Project Overview

This project showcases how to build and deploy a static web application using modern DevOps practices. It includes:

- Frontend development using HTML, CSS, and JavaScript
- Hosting on an AWS EC2 Linux instance
- Domain integration and DNS configuration
- Secure HTTPS setup with SSL certificates
- Web server configuration using Nginx
